#  APL Logistics - Late Delivery Risk Prediction

## Overview

This project predicts late delivery risk using Machine Learning.

The system was developed using the APL Logistics dataset and an XGBoost Classifier. An interactive Streamlit dashboard allows users to visualize logistics data and predict delivery risks.

## Features

- Executive Dashboard
- Risk Analytics
- Regional Analytics
